# Human Emotion Detection CNN - Streamlit App

🌐 **Live Demo**: https://edcnn-zno-app.streamlit.app/

This repository contains the Streamlit web application deployment for the Human Emotion Detection CNN project. The app provides a user-friendly interface to test the emotion recognition model by uploading facial images and receiving real-time emotion predictions.

## About This Project

This is part of a larger comprehensive deep learning project that classifies human emotions from facial images into 7 categories: angry, disgust, fear, happy, neutral, sad, and surprise. The model was trained on the FER2013 dataset using a custom CNN architecture.

**🔗 Main Project Repository**: [Human-Emotion-Detection-Using-CNN](https://github.com/znwayoo/Human-Emotion-Detection-Using-CNN)

For detailed information about:
- Model architecture and training process
- Dataset analysis and preprocessing
- Performance evaluation and results
- Technical implementation details

Please visit the main repository.

## Features

- Upload facial images for emotion prediction
- Real-time emotion classification
- Confidence scores for predictions
- User-friendly web interface
- Supports common image formats (JPG, PNG, etc.)

## Model Performance

- **Validation Accuracy**: 66.43%
- **Test Accuracy**: 65.99%
- **External Dataset (CK+)**: 68.91%
